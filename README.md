## 影响报价的五个变量

1. **带宽**：主流按带宽计费，5M、10M、20M、50M、100M 一档一档往上加，带宽越大越贵。直播这类对速度敏感的业务需要的带宽明显更高。
2. **计费方式**：按流量还是按带宽。按流量的单价通常更高，适合流量起伏大、偶尔爆发式增长的业务；带宽需求稳定的日常办公，包带宽更划算。
3. **线路地区**：美国、日韩、东南亚的网络建设和维护成本不同，跨境距离越远费用越高。
4. **节点数量**：在新加坡、德国、美国各设一个接入点，每多一个节点就多一笔费用，但多节点可以通过规模化把成本分摊下来。
5. **增值服务**：独立 IP、专线优化、注册社媒账号用的独立线路，都会额外加钱。

询价时把这五项一次性报给服务商，拿到的价格才有可比性。漏了节点数或者增值服务，后面加需求时价格往往就上去了。

## 常见问题

### 跨境电商一定要开专线吗？

看业务形态。只做一两个店铺、以访问后台为主，账号型方案够用；多店铺矩阵、做直播、团队人多业务重，专线的固定 IP 和独享带宽才真正派上用场。

### 专线和家庭宽带有什么区别？

三点：上下行带宽对称，100M 专线上下行都是 100M；固定公网 IP，可以对外提供服务，登录平台不用反复验证；独享带宽，服务质量有保证。家庭宽带共享线路、动态 IP，便宜但不适合当业务网络。

### 按流量计费和按带宽计费怎么选？

流量波动大、偶尔爆发式增长的业务选按流量；带宽需求稳定的日常办公选按带宽，单价更低。

### 怎么办理跨境电商网络专线？

两条路。找电信运营商：凭营业执照和相关文件，到当地营业厅或官网办理。找第三方跨境网络服务商：先出方案和预算，搭建完参与验收，再确认后续运维条款，方案更灵活，适合中小团队。
